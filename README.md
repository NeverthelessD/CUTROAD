## 설치

1. 위의 **앱 받기**에서 `CUTROAD.zip`을 받아 압축을 풀어요. (안에 앱과 사용 가이드가 들어 있어요)
2. `CUTROAD.app`을 **응용 프로그램** 폴더로 옮겨요. (업데이트가 동작하려면 꼭 옮겨 주세요)
3. 처음 열 때 경고가 뜨면 **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**.

사용 가이드: [`docs/CUTROAD_사용가이드.png`](docs/CUTROAD_사용가이드.png)

앱 설정과 프로젝트는 `~/Library/Application Support/CUTROAD` 한 폴더에만 저장돼요. 영상 파일은 원래 자리 그대로 써요.
