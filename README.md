## 설치

1. 위의 **앱 받기**에서 `CUTROAD.zip`을 받아 압축을 풀어요. (안에 앱과 사용 가이드가 들어 있어요)
2. `CUTROAD.app`을 **응용 프로그램** 폴더로 옮겨요. (업데이트가 동작하려면 꼭 옮겨 주세요)
3. 처음 열 때 경고가 뜨면 **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"**.

사용 가이드: [`docs/CUTROAD_사용가이드.png`](docs/CUTROAD_사용가이드.png)

### Windows (1.3.0~)

1. 위의 **앱 받기**에서 `CUTROAD-Windows.zip`을 받아 **모두 압축 풀기** → 풀린 폴더의 `CUTROAD.exe`를 실행해요.
2. 파란 **PC 보호** 창이 뜨면 **추가 정보 → 실행**.
3. 처음 한 번은 영상 도구(약 100MB)를 받아요. 자동 자막은 처음 쓸 때 받아쓰기 모델(약 490MB)을 받아요.

사용 가이드: [`docs/CUTROAD_Windows_사용가이드.png`](docs/CUTROAD_Windows_사용가이드.png) · 앱 설정과 프로젝트는 `%LOCALAPPDATA%\CUTROAD` 에 저장돼요.

앱 설정과 프로젝트는 `~/Library/Application Support/CUTROAD` 한 폴더에만 저장돼요. 영상 파일은 원래 자리 그대로 써요.
