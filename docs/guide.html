CUTROAD

가볍게 자르고, 붙이고, 바로 내보내는 영상 편집기 · 사용 가이드

macOS · Apple Silicon
새 버전이 나오면 앱이 알아서 받아요

1설치 · 시작

  • CUTROAD.app을 응용 프로그램 폴더로 옮긴 뒤 열어요
  • 처음에 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기
  • 영상(MOV · MP4) · 소리(MP3 · WAV · M4A) · 사진(JPG · PNG · HEIC)을 창에 끌어다 놓으면 바로 시작
  • 편집하면 자동으로 저장돼요. 처음 화면의 최근 프로젝트에서 다시 열어요

2컷 편집만

위쪽 [컷 편집만]을 누르면 복잡한 것 없이 자르기만 하는 화면이 나와요.

  • 재생 위치에서 여기서 자르기 ⌘B → 필요 없는 조각을 눌러 지우기 ⌫
  • 지운 조각은 빗금으로 남아서 되살리기로 되돌릴 수 있어요
  • 저장하기는 다시 인코딩하지 않아서 원래 화질 그대로, 아주 빨라요

4오른쪽 속성

  • 클립: 볼륨 · 페이드 · 속도 · 움직임 · 색감 · 블러 · 회전
  • 트랜지션 10가지: 디졸브 · 검은 화면 · 흰색 번쩍 · 와이프 · 밀어내기 · 원형 열기 · 확대 · 빙글 · 흐리게 · 블라인드
  • 텍스트: 제목/자막 · 위치 · 크기 · 배경 상자 · 나오는 시간
  • 배경음악: 볼륨 · 페이드 · 시작 위치
  • 프로젝트: 화면 비율(가로 · 세로 · 1:1) · 맞춤

5자동 자막 · 내보내기

  • 자동 자막: 맥의 받아쓰기로 영상 소리를 자막으로. 처음엔 음성 인식 허용을 눌러 주세요
  • 받아쓴 문장은 넣기 전에 바로 고칠 수 있어요
  • 내보내기 ⌘E: MP4 고화질 1080p · 4K · 용량 작게 · 세로 9:16 · 원본 그대로 · 움짤 GIF
  • 다 되면 Finder에서 보기로 바로 찾아요

6사진 + 음악으로 영상 만들기 1.1 새 기능

  • 처음 화면의 사진 + 음악으로 영상 만들기 (또는 ⇧⌘N)
  • 사진 폴더를 고르면 하위 폴더까지 JPG · PNG · HEIC 사진을 모두 불러와요
  • 배경음악을 고르면 박자(BPM)를 찾아서, 사진이 박자에 맞춰 바뀌어요
  • 음악 흐름(도입 · 전개 · 절정 · 쉬어 가기 · 마무리)을 읽어서, 절정은 빠르게 몰아치고 도입 · 마무리는 길고 부드럽게 편집해요
  • 스타일 7가지: 깔끔하게 · 여행 브이로그 · 감성 필름 · 신나게 · 레트로 · 흑백 시네마 · 맡기기
  • 효과: 움직임 8 · 넘기기 10 · 색감 8 · 박자 효과 3 (여러 개 고르면 번갈아 써요)
  • 다 만든 뒤 효과 다시 섞기 · 설정 바꿔서 다시 만들기, 사진 끝을 끌면 박자에 딱 붙어요
  • 같은 효과를 영상 클립에도 쓸 수 있어요 (오른쪽 속성 → 움직임 · 색감)
